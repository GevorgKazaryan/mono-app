Why doesn’t Mono turn the screen grey by itself?

iOS doesn’t let apps change how the whole screen looks. Only you can, with Grayscale and Reduce White Point. Mono walks you through a Shortcuts automation that does this every night. Open Mono › Settings › Set up the ink screen.

How do I set up the ink screen?

  1. Settings › Accessibility › Display & Text Size › Color Filters: choose Grayscale, then turn Color Filters off.
  2. Shortcuts › Automation › + › Time of Day at your bedtime, Daily, Run Immediately. Add Set Color Filters (On), Set Reduce White Point (On) and Mono › Start Ink Hours.
  3. Add a second automation at your wake time with the same actions set to Off and Mono › End Ink Hours.

An app I quieted still opens.

Check that Screen Time access is allowed (Mono › Settings) and that the app is in your list. Screen Time also needs to be on in iOS Settings.

How do I end ink hours early?

On Mono’s home screen, press and hold the button for three seconds. The delay is on purpose.

How do I stop Mono completely?

Turn off “Every night” in Mono › Settings, or delete the app. Deleting it removes all shields and data.
